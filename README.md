# Sagapi Gamedata

An automated CLI pipeline designed to safely extract, decrypt, and decode Arknights game data across multiple regional servers. 

> **IMPORTANT:** The parsed, human-readable game data files (.json) generated by this tool are continuously deployed and maintained in the **`gamedata`** branch.

## Architecture & Key Features

* **Powered by Sagapi-Flatbuffers:** This project relies heavily on the **[sagapi-flatbuffers](https://github.com/elbriant/sagapi-flatbuffers)** repository. During execution, it automatically fetches the latest `.fbs` schemas from that repository and orchestrates `flatc` to parse the raw Unity `.bytes` files into strict, properly hydrated JSON structures.
* **Resilient Decryption (Fallback):** If a FlatBuffers schema is missing, or if the file contains Level/Lua data, the pipeline automatically falls back to decrypting Hypergryph's custom AES-CBC implementation (Cryptic A) and parsing the underlying BSON/JSON payloads.
* **Autonomous CI/CD:** Fully automated via GitHub Actions. It listens for `repository_dispatch` signals triggered by `sagapi-flatbuffers` for major schema updates, and runs scheduled CRON jobs to detect minor server content patches.

## Prerequisites

* Dart SDK `>= 3.11.0`
* .NET SDK `8.0.x` (Required to run the internal C# extraction utility)
* Git

## Quick Start

1. Fetch dependencies:
   ```bash
   dart pub get
   ```

2. Execute the pipeline:
   ```bash
   dart run bin/sagapi_gamedata.dart --server <region> [options]
   ```

### Core Arguments
* `--server` : Target server to process (`all`, `cn`, `en`, `jp`, `kr`, `tw`).
* `--force` : Ignores local version hashes and forces a full redownload of all assets.
* `--failfast` : Throws a fatal exception immediately upon encountering a decoding error. Highly recommended for CI/CD environments to prevent corrupt commits.
